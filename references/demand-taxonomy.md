# 需求分类维度与打分模型

## 一、8+1 维度定义

把每条评论归到**最主打的那一类**（一跨多类时取主导意图）。`xhs_collect.js` 已用 `classifyComment()` 做噪声过滤，但**需求维度需人工确认**——脚本只做噪声标记，不做语义分类。

| 维度 | 它在说什么 | 典型原声（实测外贸赛道） | 判断技巧 |
|---|---|---|---|
| **内容缺口** | 求具体方法、教程、步骤 | 「这个展会名单从哪里找？」「参展公司那不是同行吗」 | 出现「怎么/哪/如何/从哪」+ 疑问句 |
| **痛点抱怨** | 使用中卡住、踩坑、没效果 | 「领英上加好友都没被通过根本聊不起来」 | 负面情绪词 + 具体场景 |
| **场景需求** | 绑定人群、场合、资质 | 「你英语怎么样？」「你是通过什么收款」 | 出现具体身份/条件/场景 |
| **价格性价比** | 贵不贵、值不值、有无免费额度 | 「阿波罗是付费的吗」「不用我花好几万去投流」 | 出现价格、预算、免费、性价比 |
| **决策犹豫** | 拿不准选哪个、先做哪步 | 「可以一开始就打电话开发吗 还是先邮件」 | 二选一式提问、对比 |
| **渠道真伪** | 怕被骗、来源可信度、合规 | 「这年头太多骗子了」「需不需要个税啊」 | 出现骗子、真假、靠谱、税 |
| **情感共鸣** | 情绪认同、身份确认 | 「外贸最磨人的不是找不到客户，是最后单还是黄了」 | 长句、有情绪转折、无提问 |
| **功能需求** | 想要某功能/效果 | 「求持妆久的」 | 出现具体功效/功能词 |
| **情感身份** | 想要的感觉、人设 | 「想看起来松弛感」 | 描述风格/自我形象 |
| 其他 | 不归类的零散闲聊 | 「LinkedIn」「速通鹿」 | 判定后优先归入上面 9 类 |

## 二、热度打分模型

每条评论打 5 个指标，**热度分 ≥0.7 = 必做选题；0.4–0.7 = 储备；<0.4 = 观察**。

| 指标 | 怎么算 | 权重 |
|---|---|---|
| 出现频次 | 同类需求在样本中出现的次数（汇总时统计） | 高 |
| 互动量 | 该评论本身的点赞数 | 0.35 |
| 需求强度 | 1–5：提问式/抱怨式=强(4–5)，闲聊=弱(1–2) | 0.25 |
| 共鸣信号 | 有无人跟评「我也是」「蹲一个」/有展开回复 | 0.2 |
| 商业相关 | 是否与产品/变现直接相关 | 0.2 |

```
热度分 = 互动量归一 × 0.35 + 需求强度 × 0.25 + 共鸣信号 × 0.2 + 商业相关 × 0.2
互动量归一 = 该评论赞数 / 样本内最高赞数
```

**排序时优先看「痛点抱怨」和「内容缺口」的交集**——既痛、又没被满足的，是最好的选题位。

## 三、噪声识别（必做，污染结论）

实测样本中 **40% 是引流广告 + 水军**。特征：

| 类型 | 特征 | 脚本正则 |
|---|---|---|
| 货代/物流 | 货代、海运、清关、DDP、整柜、专线 | `ad_freight` |
| 公司注册 | 注册公司、商标、财税代理、账户 | `ad_company` |
| 建站/SEO | 独立站、建站、Google SEO、服务器 | `ad_website` |
| 拼团/引流 | 拼团、招募、合伙人、课程、训练营 | `ad_groupbuy` |
| 留联系方式 | 加微信、VX、私我、评论区扣 1 | `ad_wechat` |
| 资源暗号 | 「打个已guan可以拿」「已guan」「發尼了」 | `ad_resource` |
| 软广 @人 | 「可以找他哦@XX」「私我」「主页有」 | `ad_softtag` |
| 博主刷屏 | 作者本人反复回「消息你了」等 | `author_reply`（靠 DOM `作者` 徽标识别） |
| 模板化水军 | 「干货满满」「分析得特别透彻」「稳扎稳打才是正道」 | `water_army` |
| 无信息量 | 「加油」「优秀」「收藏了」 | `water_dup` |

**判断真需求的信号**：短、具体、提问式、带真实痛点。

**噪声比例诊断**：若 `stats.noise / stats.comments > 0.5`，说明关键词选得太偏工具/服务品类（这类内容评论区本来就是同行引流盘），应换成**买家视角词**或换赛道。**博主刷屏型笔记（作者逐条回复）噪声可达 58%，此时应重点看被标为 real 的高赞评论。**

## 四、跨批次累积

单次样本（4 篇 / 28 条真实需求）只能给方向，不能下结论。建议：

- 每赛道累积 **≥3 批、共 ≥50 条**真实评论再定选题排期
- 每次把打分表追加进同一 Excel，便于看需求频次随时间的变化
- 关注的信号变化：某维度占比上升 = 用户阶段在迁移（如从「找客户」转向「要成交」）
